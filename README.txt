MEXC Mobile Scalper — Mobile Edition
=======================================

واجهة هاتف محسّنة بنمط لوحة تداول داكنة، مع:
- بطاقة العملة والسعر الحالي.
- بطاقة الربح المباشر.
- API Key / Secret Key.
- مبلغ الصفقة وTP وSL.
- أزرار بدء وإيقاف وإغلاق.
- سجل مباشر.
- استمرار حفظ الصفقة في SQLite.

بناء APK:
------------
على Linux أو WSL بعد تثبيت Buildozer:
    buildozer android debug

سيظهر ملف APK في:
    bin/

تنبيه:
-------
هذا التطبيق يتعامل مع MEXC API وقد يرسل أوامر تداول حقيقية.
لا تمنح API صلاحية سحب الأموال، ولا تشارك Secret Key.
