# بناء APK باستخدام GitHub Actions

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع ملفات المشروع إلى المستودع.
3. تأكد من وجود:
   .github/workflows/build-apk.yml
4. افتح تبويب Actions.
5. اختر Build MEXC Mobile Scalper APK.
6. اضغط Run workflow.
7. انتظر انتهاء البناء.
8. افتح نتيجة التشغيل الناجحة.
9. من Artifacts حمّل MEXC-Mobile-Scalper-APK.
10. فك الضغط وستجد ملف APK.

ملاحظة:
المشروع يحتوي على وظائف تداول حقيقية في MEXC. استخدم مفاتيح API بدون صلاحية السحب واختبر بحذر.
